# GitHub Practice Repo

A tiny sandbox repo for practicing the full GitHub contribution workflow:

**read → branch → codespace → create → edit → commit → push → pull request**

## For students

👉 Start here: [INSTRUCTIONS.md](INSTRUCTIONS.md)

## What's in here

```bash
.
├── index.html          # Homepage that will list student pages
├── style.css           # Simple dark-mode styling
├── script.js           # Tiny bit of JS
├── students/           # Each student adds their own folder here
├── INSTRUCTIONS.md      # Step-by-step guide for students
└── .devcontainer/       # Codespaces configuration
```
